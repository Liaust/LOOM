# Project Map

## Structure

- `.project/`: editable project purpose, progress, decisions and workflow.
- `.loom/`: project identity and explicit technical resource declarations.
- `notes/`: ordinary authored notes and source material.
- `repos/`: ordinary folder for code repositories when useful; no Git is created.

Add meaningful folder descriptions here as the project evolves. This map does
not register resources or grant access. Git repositories retain their own
instructions, build commands and history.
