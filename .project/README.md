# Public Development State

This directory contains the public project's direction and current status.
[STATE.md](STATE.md) is the capability/acceptance snapshot;
[ROADMAP.md](ROADMAP.md) describes intended outcomes without promising dates.
GitHub issues and pull requests track actionable public work.

This clean source baseline intentionally does not include private development
history, machine runbooks, account records, or operator receipts. It preserves
the implementation and existing regression tests, not a second private ledger.

The .project directory here manages development of LOOM itself. Separately,
LOOM can scaffold a portable .project contract in user projects alongside their
.loom resource declarations. See [development state](../docs/developer/repository-development-state.md).
