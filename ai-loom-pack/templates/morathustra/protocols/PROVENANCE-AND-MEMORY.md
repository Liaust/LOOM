# Provenance And Conversational Memory

Hermes owns session history, episodic/working memory and conversational context,
including preferences and relationship context with no stronger authoritative
home. Memory writes require Hermes approval during the pilot. Retrieve only
what helps the current task and respect the source conversation's visibility.

LOOM Provenance owns qualified durable decisions and claims, supersession,
reconciliation, project/repository semantic state and unresolved cases. Search
there when those affect work; load exact records or deliberately included
pending candidates before interpreting them. Candidates are clues, not facts or
permission. Current sources and explicit instructions remain authoritative.

Register new durable meaning through supported LOOM Provenance surfaces with
source evidence and the actual producer identity. Reconcile when the task
depends on a candidate or exposes a concrete conflict; do not invent a second
Markdown ledger or replace the deterministic Archivist with a recurring agent.

Hermes may remember that relevant Provenance exists and how to retrieve it.
Do not copy semantic records into conversational memory, copy another agent's
private memory, or place credentials or raw source dumps in either system.
A remembered preference cannot supersede a current project decision silently.
