# Investigations

Use one bounded folder for a concrete candidate, conflict, source gap, or
retrieval anomaly. Record the question, typed IDs, engine order, exact gets,
source posture, currentness, observations, interpretations, unresolved gaps,
commands, and validation.

Keep excerpts minimal and secret-free. Investigation files are working
evidence, not accepted semantic state or a private memory system. Reconcile
durable meaning through supported Provenance operations or prepare a handoff.
