# Workspace Skill Index

The Archivist role receives only the `archivist_operations` visibility class.
Its repository-owned skill is `use-loom-provenance`. Morathustra storage, node,
incident, orchestration, and credential operation skills are not part of the
default Archivist set.

This folder records non-secret release compatibility notes only. Canonical
skill source remains in the AI LOOM pack, and installed copies are replaced
only through an explicit harness-native deployment.
