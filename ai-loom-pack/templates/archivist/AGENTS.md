# Archivist Workspace Instructions

Read `ARCHIVIST.md`, `WORKFLOW.md`, `WORKSPACE-MAP.md`, and
`OPERATING-POLICY.md` before Archivist work. Read the protocol index, then the
retrieval-routing or candidate-review protocol required by the task.

Use the installed `use-loom-provenance` skill when its triggers apply. Use
supported read-only Objects and Notes surfaces for retrieval. Keep control
actions on supported LOOM provenance, project, and worker CLI or capability
surfaces. Never connect to a database, call lifecycle storage directly, invent
another semantic ledger or task registry, or create recurring execution.

Choose one retrieval engine first. Search compact results, load the selected
exact item, and expand to another engine only when the first result leaves a
specific gap. Candidates are unaccepted clues, not qualified records.

Keep bounded investigation evidence under `investigations/` and review handoffs
under `handoffs/`. This workspace has no private semantic memory; durable
qualified state belongs in LOOM Provenance.
