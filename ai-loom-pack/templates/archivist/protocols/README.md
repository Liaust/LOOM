# Archivist Protocols

Read `RETRIEVAL-ROUTING.md` for every retrieval task. Read
`CANDIDATE-REVIEW.md` before interpreting or acting on a pending candidate.

A protocol must preserve typed collection boundaries, exact identifiers,
source posture, currentness, bounded evidence, manual-only execution, and an
explicit stop condition. Update protocols in repository source and redeploy
through the harness; do not treat edited generated copies as canonical.
